# DPC 項目管理平台｜版本紀錄

線上版：https://claude.ai/artifact/LdrkGBCvMpawY5237hdM4H
GitHub 版：https://cbryant1022.github.io/dpc/report/

## v2.5（2026-11-24 14:50）
- 印刷圖稿新增三個計算口徑：總版號數（不重複斬刀編號）、實際圖稿數量（段別數量合計）、實際顏色數量（顏色數量合計）
- 產出量新增「印刷圖稿｜版號・圖稿・顏色」近 12 個月表，含每版圖稿數與每張圖稿工時
- 資料格式升級（schema 5）：之前匯入的 Excel 需重新匯入一次才會有版號／圖稿／顏色數

## v2.4（2026-11-24 14:40）
- 新增登入：開啟平台需輸入帳號密碼，初始資料改為加密檔（AES-256），沒有密碼無法讀取
- 本月重點結論不再顯示「資料不足」的項目（交期頁仍保留覆蓋率提示）
- 側欄新增「登出」

## v2.3（2026-11-24 14:25）
- 劃線模卡片新增工序拆解：繪製建模／3D 打印／檢查修改／3D 掃描（依工作日誌作業分類與內容判定）
- 3D 打印卡片改顯示人員操作工時（切片打印＋打磨後處理，含在劃線模工時內）與每只人員工時，另列機器運轉機時
- 3D 掃描卡片改顯示人員掃描工時，並與標準工時（10 分鐘/尺碼）比較實際效率

## v2.2（2026-11-24 09:50）
- 本月重點結論新增「補充結論」：可自行新增、編輯、刪除，並標示達標／接近／未達／資訊／待追蹤
- 補充結論依月份保存，共享模式下所有檢視者都看得到；複製月報摘要與連續模式會一起帶出

## v2.1（2026-11-24 09:40）
- 圖表點一下即可固定顯示數值，iPad／手機也能看；圖表可用鍵盤 Tab 逐月查看
- 每張趨勢圖新增「表格檢視」，可直接看 12 個月數字
- 總覽移除不同單位相加的「完成案件」，改為「主要產出」（印刷圖稿筆、劃線模支、3D建模件）
- OTD 新增計畫日覆蓋率；低於 80% 顯示「資料不足」，不再顯示綠色達標
- 網址記住目前頁面、月份、組別，可直接傳連結；瀏覽器上一頁可回到前一個篩選
- 手機版：選單改為頂部橫滑分頁列、圖表字級放大、KPI 標題不再被切掉
- 說明文字加深、焦點框加粗、提示訊息可被螢幕閱讀器讀出

## v2.0（2026-11-18 10:19）
